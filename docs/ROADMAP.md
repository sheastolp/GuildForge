# GuildForge Roadmap

## Phase 1 — Public Launch (Now)
- Open-source all core tools under the GuildForge brand.
- Publish monorepo or individual repos.
- Simple landing page live.
- Clear setup guides so anyone can point bots and overlays.

## Phase 2 — Polish & Community
- Improve documentation and examples.
- Collect feedback from early streamers.
- Add more themes / commands / overlay styles.
- Create Discord server for GuildForge users.

## Phase 3 — Unified Experience
- Shared authentication (Twitch / Discord login).
- Central dashboard (optional) that links all tools.
- Cross-tool features (e.g. chatbot events triggering overlays).

## Phase 4 — Monetization (Paywall)
- Free forever: core chatbots, basic overlays, Hushwave.
- Pro tier examples:
  - Hosted bot instances (no need to run locally)
  - Advanced themes, animations, and sound packs
  - Priority support
  - Higher rate limits / more concurrent features
  - Unified analytics
- One GuildForge account unlocks Pro across the whole suite.

Pricing and exact feature split can be decided later based on usage data.
