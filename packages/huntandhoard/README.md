# GuildForge Hunt & Hoard

**Idle, no-end RPG game** powered by a Twitch chatbot.

Part of the **GuildForge** suite.  
*Tools for the guild. Power for the stream.*

## Overview
Hunt & Hoard turns your chat into a persistent idle RPG. Viewers join, hunt, gather, and build their hoard over time with no forced ending.

## Setup
1. Clone or download this package.
2. Install dependencies and configure your Twitch bot credentials.
3. Point the bot at your channel.
4. Start the game loop.
