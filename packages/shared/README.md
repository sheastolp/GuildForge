# GuildForge Shared

Common utilities, Twitch helpers, authentication helpers, and shared code used across GuildForge products.

## Purpose
Keep the individual products DRY by centralizing:
- Twitch API / EventSub helpers
- Auth & token management
- Shared types / constants
- Logging and utility functions

## Usage
Import from this package inside the other GuildForge products as needed.

> **Note:** Populate this folder with the actual shared modules when you organize your codebase.
