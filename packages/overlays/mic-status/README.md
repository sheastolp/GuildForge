# GuildForge Mic Status

**Live microphone status overlay** for OBS.

Part of the **GuildForge** suite.  
*Tools for the guild. Power for the stream.*

## Overview
Shows real-time microphone activity (speaking / muted / levels) as a clean overlay. Perfect for letting viewers know when you are live on mic.

## Setup
1. Host or open the overlay page.
2. In OBS, add a **Browser Source** and point it at the overlay URL.
3. Position and size the source as needed.
4. Configure any audio input detection settings required by the overlay.
