# Contributing to GuildForge

Thank you for your interest in improving GuildForge!

## How to Contribute

1. **Fork** the repository (or the specific product package).
2. Create a feature branch (`git checkout -b feature/amazing-thing`).
3. Make your changes.
4. Commit with clear messages.
5. Open a Pull Request against the `main` branch.

## Guidelines

- Keep changes focused. One feature or fix per PR is preferred.
- Follow the existing code style of the package you are editing.
- Update documentation (README or docs/) when you add or change features.
- Test your changes with a real Twitch channel / OBS setup when possible.
- Be respectful in issues and pull requests.

## Reporting Bugs & Requesting Features

Open an issue and include:
- Clear title
- Steps to reproduce (for bugs)
- Expected vs actual behavior
- Screenshots or logs if relevant
- Which product the issue affects (Guildscribe, Hunt & Hoard, Hushwave, overlays, etc.)

## Code of Conduct

Be kind. Harassment, toxicity, or bad-faith contributions will not be tolerated.
