# GuildForge

**Forge your stream. Command your chat.**  
**Tools for the guild. Power for the stream.**  
**Chatbots, overlays & ambient tools — forged for streamers.**

GuildForge is a suite of tools built for Twitch streamers and content creators. From fantasy-themed chatbots to OBS overlays and ambient music, everything lives under one brand so you can equip your stream and grow your community.

---

## Products

| Product | Description | Status |
|---------|-------------|--------|
| **[Guildscribe](packages/guildscribe)** | DnD-themed Twitch chatbot — a powerful alternative to StreamElements | Active |
| **[Hunt & Hoard](packages/huntandhoard)** | Idle, no-end RPG game powered by a Twitch chatbot | Active |
| **[Hushwave](packages/hushwave)** | Ambient music generator for Windows | Active |
| **[Chat Overlay](packages/overlays/chat)** | Clean, customizable OBS browser-source chat overlay | Active |
| **[Mic Status](packages/overlays/mic-status)** | Live microphone status overlay for OBS | Active |

---

## Quick Start

1. Clone this repository (or the individual product repos).
2. Follow the setup instructions inside each product folder.
3. Point your Twitch bot accounts / OBS browser sources at the tools.
4. Go live.

Detailed setup guides live in each product’s `README.md` and in the [`docs/`](docs/) folder.
